# 반려동물 자동급식기 D2C 사이트 — 프론트엔드 데모

출시 전 독립 프론트엔드 데모. 식스샵 장바구니·주문·결제와 **연동되어 있지 않습니다.**

## 실행

빌드 단계 없음. 정적 파일만 사용.

```bash
cd feeder-site
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`index.html` 더블클릭으로도 열립니다 (ES 모듈 미사용).

## 구조

```
feeder-site/
├── index.html              # 시맨틱 마크업, SEO 메타, 9개 섹션
├── assets/css/tokens.css   # 디자인 토큰 (색·타입·간격·모션)
├── assets/css/main.css     # 컴포넌트·섹션 스타일, 반응형, 모션 감소 대응
├── assets/js/data.js       # 콘텐츠 단일 소스 — 확정 자료는 여기만 수정
├── assets/js/components.js # 데이터 → HTML 순수 렌더 함수 (재사용 컴포넌트)
├── assets/js/main.js       # 렌더링·인터랙션·로딩/오류 상태
└── assets/img/*.svg        # 임시 일러스트 (실제 촬영본으로 교체 대상)
```

## 데이터 교체 방법

- 사양 확정 → `data.js`의 `comparison`, `features[].availability` 값을 `'yes' | 'no' | 'tbd'`로 변경.
- 가격 → `comparison`의 가격 행 수정. (`pricePublished`는 향후 상품 카드 가격 영역용 예약 필드)
- 스토어 링크 → `storeUrl`에 식스샵 상품 URL 입력 시 상세 다이얼로그 구매 버튼 활성화.
- 브랜드명 → `brand.name` 입력 시 헤더·푸터 워드마크 자동 교체.
- 후기 → `reviews`에 `{ text, author, model }` 형식으로 **실제 구매 후기만** 입력.

## 데이터 원칙 (현재 상태)

| 항목 | 상태 | 근거 |
|---|---|---|
| 기본형 = 버튼 제어 | 확정 | 브리프 |
| 프리미엄형 = 카메라 + 앱 제어 | 확정 | 브리프 |
| 기본형 카메라·앱 "미포함" | **추정** | 브리프의 두 모델 구분에서 추론. 실제 사양 확인 필요 |
| 프리미엄형 본체 버튼 | 미확정 | 표시: 사양 확인 중 |
| 예약 급식·급식량 조절 | 미확정 | 두 모델 모두 사양 확인 중 |
| 가격·용량·크기·전원·인증 | 미확정 | 표시하지 않음 |
| 제품·라이프스타일 이미지 | 임시 일러스트 | 화면에 "임시 일러스트" 표기 |
| 앱 화면 | 시뮬레이션 | 화면에 "시뮬레이션 화면" 표기 |
| 고객 후기 | 없음 | 출시 전 안내로 대체 |

## 상용화 전 해결 과제

1. **브랜드명·로고** 확정.
2. **실제 제품 사양** 확정 → `data.js` 반영. 기본형 카메라·앱 미포함 추정도 검증.
3. **제품·라이프스타일 사진** 촬영 → SVG 교체. WebP/AVIF + `srcset` 적용.
4. **실제 앱 화면** 확보 → 시뮬레이션 교체.
5. **인증**: 전기용품 KC 안전인증, 무선 기능(앱·카메라) 제품의 전파법 적합성평가 여부 확인 및 표기. (해당 여부는 제품 사양 기준 확인 필요)
6. **법정 표기**: 사업자 정보(상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 연락처), 이용약관, 개인정보처리방침. 현재 "확정 후 기재".
7. **배송·교환·반품 정책** 확정. 청약철회 기간·예외 조건은 「전자상거래 등에서의 소비자보호에 관한 법률」 기준으로 법무 검토.
8. **식스샵 연동 방식** 결정 (아래).
9. 공개 배포 시 `index.html`의 `<meta name="robots" content="noindex">` 제거, OG 이미지 절대경로 JPG/PNG(1200×630)로 교체, 데모 배너 제거.
10. 카메라 제품 특성상 **개인정보·영상 데이터 처리 고지** 필요 여부 법무 검토.

## 식스샵 연동 — 확인 필요

연동 가능 범위 미확인. 검토할 선택지:

- **A. 식스샵 디자인 편집기 + 커스텀 HTML/CSS 섹션**: 이 데모의 섹션을 이식. 결제·장바구니는 식스샵 기본 기능 사용. 구조가 프레임워크 없는 정적 HTML이라 이식 용이.
- **B. 별도 랜딩 + 식스샵 상품 페이지 링크**: `storeUrl`만 연결. 가장 단순.

식스샵이 허용하는 커스텀 코드 범위(스크립트 허용 여부 등)는 플랜별로 다를 수 있으므로 공식 문서·고객센터 확인 후 결정.

## 점검 결과 (로컬 Chromium, 2026-11-04)

- 1440px·390px 가로 스크롤 없음.
- 모바일 메뉴(열기/Esc/링크 이동), 기능 탭(클릭·화살표·Home), 비교표 차이점 필터, FAQ 아코디언(키보드), 이미지 뷰 전환, 상세 다이얼로그(Esc), 앱 시뮬레이션, 헤더 상태, 모션 감소 설정 — 자동 테스트 통과.
- 컨테이너 네트워크 정책상 Pretendard CDN(jsdelivr) 미로딩 상태로 점검. 실제 브라우저에선 Pretendard 적용, 실패 시 Noto Sans KR 대체.
